Logical Consistency as a Bridge: Improving LLM Hallucination Detection via Label Constraint Modeling between Responses and Self-Judgments

Hao Mi, Qiang Sheng, Shaofei Wang, Beizhe Hu, Yifan Sun, Zhengjia Wang, Hengqi Zeng, Yang Li, Danding Wang, Juan Cao

Institute of Computing Technology, Chinese Academy of Sciences  ·  University of Chinese Academy of Sciences

Paper (TBA) GitHub

TL;DR

Existing hallucination detectors either extract micro-level intrinsic patterns (hidden states, logits, attention) or elicit macro-level self-judgments — but treat these two inherently coupled signals in isolation. LaaB bridges both views by treating the LLM's self-judgment as another response subject to hallucination, and exploiting the logical constraint between response and judgment labels via mutual learning for more accurate detection.

Comparison of existing detection paradigms (a–b) and LaaB (c). Unlike methods that rely solely on intrinsic patterns or symbolic judgments, LaaB bridges both views via logic-constrained mutual learning.

Contributions

  • Concept: We propose to view the LLM's self-judgment as a special response that can itself be checked for hallucination, whose result bridges a logical constraint enabling integration of dual-view predictions.
  • Method: We design LaaB, which bridges prediction signals from both intrinsic patterns and self-judgments, and builds a mutual learning framework for accurate hallucination detection.
  • Performance: Experiments on 4 datasets, across 4 LLMs, against 8 baselines show LaaB effectively enhances hallucination detection without significant additional inference cost.

Method

Overall architecture of LaaB. (a) Response Hallucination Modeling extracts intrinsic features from the response generation. (b) Self-Judgment Hallucination Modeling introduces a meta-judgment process on the verbal judgment. (c) Logic-Constrained Mutual Learning bridges both views via logical consistency.

(a) Response Hallucination Modeling
Detector Dr classifies response factuality using intrinsic features (hidden states, logits, or attention scores) extracted during response generation.
(b) Self-Judgment Hallucination Modeling
We treat the LLM's self-judgment ("Yes"/"No") as a generated artifact subject to evaluative hallucination. Detector Dj predicts its factuality via the same intrinsic features — a meta-judgment.
(c) Logic-Constrained Mutual Learning
The inherent logical dependency — if the judgment is "Yes", labels agree (Lr = Lj); if "No", they oppose (Lr = 1 − Lj) — is enforced via Huber loss with confidence-aware weighting. A two-stage strategy first trains Dr and Dj asynchronously, then jointly fine-tunes them. At inference, only Dr is deployed.

Key Findings

1) Consistent improvement across diverse intrinsic patterns and LLM families. LaaB enhances detection when applied to hidden states (SAPLMA), logits (Logits Lens), and attention patterns (Lookback Lens), across model scales from 7B to 70B and architectures including LLaMA, Qwen, and Mistral.
2) Hidden-state-based SAPLMA benefits most from LaaB. Denser hidden-state representations carry more informative factuality signals, yielding the best results under LaaB enhancement in the majority of settings.
3) Intrinsic patterns outperform self-judgments and sampling-based methods. Detectors leveraging internal model representations encode richer factuality signals than discrete token-level outputs, and LaaB's mutual learning provides an effective mechanism for exploiting them.

Further Analysis

Prediction correctness transitions before and after applying LaaB. A substantial portion of previously wrong predictions are corrected.

LaaB brings greater accuracy improvement for longer responses, suggesting self-judgment compresses factuality into a single token, mitigating sparsity.

Conclusion

We introduced LaaB (Logical Consistency-as-a-Bridge), a framework that bridges micro-level intrinsic neural patterns and macro-level symbolic self-judgments for LLM hallucination detection. By introducing a "meta-judgment" process and enforcing the inherent logical constraint via mutual learning, LaaB improves hallucination detection for most base models without significant additional inference cost — only Dr is deployed at test time.

Future Work: (1) Extending LaaB for long-article hallucination detection; (2) Multi-modal scenarios; (3) Unified framework integrating LaaB with fact-checking pipelines.
